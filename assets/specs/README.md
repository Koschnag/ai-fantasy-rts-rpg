# Asset-Spezifikationen

Jede Generierung beginnt mit einer bereinigten, intern begründeten Spezifikation. Sie beschreibt Zweck, Form-, Material-, Farb-, Kamera- und Budgetregeln, ohne ein fremdes Werk als Produktionsreferenz zu verwenden.

Die Spezifikation wird vor dem Generierungslauf gehasht. Rohoutputs bleiben unter `assets/quarantine/`; ihre Manifeste unter `assets/manifests/` dürfen den Status `approved` erst nach dem ausführbaren T-003-Gate erhalten.
