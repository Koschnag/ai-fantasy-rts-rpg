# Akzeptierte Laufzusammenfassungen

Hier können bereinigte Abschlussberichte wichtiger KI-Läufe aufgenommen werden. Rohereignisse, große Artefakte und Toolausgaben bleiben unter `.ai/runtime/runs/` lokal und werden nicht automatisch versioniert.

Eine akzeptierte Zusammenfassung nennt mindestens Run-ID, Aufgaben-IDs, Ausgangs- und End-Commit, erfüllte Kriterien, Prüfungen, relevante Entscheidungen und verbleibende Risiken. Sie darf keine Secrets oder vollständigen fremden Inhalte enthalten.
